# ApkLab — UI/UX requirements

## Design direction
Material Design with a system appearance preference.

## Theme tokens
| Token | Value |
|---|---|

## Screen hierarchy
1. Entry and purpose.
2. Primary action.
3. Progress or result.
4. Review, edit, and export.

## Accessibility
Use visible focus, keyboard navigation, semantic labels, and color contrast appropriate for the selected palette.
